# Blue Fit FAQ

## Getting started

**What does Today show?**
Today's day from your current plan: its name, a moving line man for each exercise, and exercises · sets · ~minutes. Tap an exercise for its how-to. Press and hold to reorder (saves to the plan).

**Can I do another day's workout?**
Yes. Tap any day in the week strip, then **Start** that day.

**Why does it say Rest day?**
That weekday has no exercises in your plan.

**Can I run two workouts at once?**
No. One at a time. While one runs, the dock shows **Back to workout**.

**What if I close the app mid-workout?**
Nothing is lost. Reopen it and the workout is back where you left it.

## Logging sets

**What are W, D, F and the numbers?**
Tap the set's button to cycle: number = working set → **W** warm-up → **D** drop set → **F** failure set.
- Warm-up: doesn't count for weekly sets, tonnage or PRs.
- Working: counts 1 set.
- Failure: a working set taken until no clean rep is left. Counts 1 set.
- Drop: lighter, no rest, right after the last set. Counts ½ set.

**Why won't a set mark done?**
It needs reps and a weight (no weight needed for bodyweight exercises). The missing field turns red.

**What is pre-filled?**
Last time's weights and reps, per set. First time: reps at the bottom of the range, weight empty.

**I changed set 2. Why did set 3 change too?**
On a set not done yet, the later not-done sets of the same type copy the change. A done set changes alone.

**What does the swipe on an exercise card do?**
Swipe left for: Swap · Superset · Note · Warm-up · How to · Remove.

**Can I fix a workout later?**
Yes. History → the workout → **Edit workout**. It changes only that workout, never the plan.

**What happens to sets I didn't do?**
Finish drops them. They show as dark red "skipped" in the workout's sets per muscle.

## Weights

**What number do I type?**
Exactly what's loaded. No bar math.
- Barbell, Smith, leg press: plates on **one side**, bar not included.
- T-bar row, Kelso shrug (one sleeve): all the plates on it.
- Dumbbells: **one hand**.
- EZ / preacher bars: the number on the bar.
- Machines and cables: the stack number.
- Example: Smith squat with 2 × 45 on each side → type 90.

**Is there a bar-weight setting?**
No.

**How is tonnage counted then?**
Weight × reps of done sets (not warm-ups). Per-side and per-hand weights count twice (both sides were lifted). The bar is never added.

## Progression

**How does it decide to go up?**
Double progression: add reps until every set hits the top of the range, then add weight. It says **Go up** when:
- the failure set beat the top by 3+ reps, or
- every set hit the top two workouts in a row, with no failure set testing it.
- Example: plan 10–12, 100 × 12, 12, 12 two workouts running → "Go up to 110 × 10".

**How much does it add?**
One step of the exercise. From 40 lb up it rounds up to the next 10 (e.g. 100 + 5 → 110).

**Why "hold" after I hit the top once?**
Once can be a one-off. No tip shows; the app tests it with a failure set next time when it safely can.

**What's the failure set rule?**
Every set stops a couple of reps short of failure, so a failure set 2 over the top is right on target, not proof. 3+ over proves the weight is too light: go up at least one step (+10 lb when it was 5+ over).
- Plan 8–12: failure at 14 → stay. Failure at 15 → go up.

**When does it say go down?**
Last time's first set fell 3+ reps short of the bottom of the range. 1–2 short: stay and add reps.
- Plan 12: got 9 → "Go down", with a weight that should give 12.

**What's the "New rep range" tip?**
When today's range starts higher than last time's (e.g. a new plan), it suggests the weight with the same effort at the new reps.
- Last time 180 × 10, now 12–15 → "Start at 170 × 12".

**What does Use do?**
Fills the suggested weight and reps into the sets not done yet.

**Why no tip most of the time?**
On purpose: tips show only when the weight should change. Otherwise just beat last time.

## Workout tips

**What tips can show on an exercise?**
- Blue **Go up / Go down / New rep range** (with Use).
- **Last set to failure** (amber flame), with a **Why?**.
- **+1 set**: a muscle fell behind this week from skipped work.
- Amber effort note: your failure set showed the weight was too light.
- All of them: Settings → Inline workout tips. Extra sets and app-picked failure: Settings → Auto-adjust workouts.

**Which exercises get a failure set?**
For Mass gain and Endurance only (not Strength, Maintain, deloads, or under 1 year lifting). Safe ones only: machines, cables, Smith, bodyweight, free-weight isolation. Up to 3 a workout (fewer when cutting, sleeping under 6 h or 40+). Usually the last exercise for a muscle that isn't trained again within 2 days.

**Can I control failure myself?**
Yes. Plan → tap the exercise → Last set to failure: Auto / On / Off. Your choice always wins.

**What is the "+1 set"?**
When skipped sets leave a muscle behind this week, the next workout that trains it adds one set to its last exercise for it (max 4 sets on that exercise, never past the weekly max).

## Rest timer

**When does it start?**
When you mark a set done (Settings → Start rest timer when a set is done). Not after the last set of the workout, and not between superset exercises: it rests only after each round.

**How long is it?**
The exercise's rest from the plan. Default 2 min (Settings → Default rest).

**Can I change it while resting?**
Yes: −15 s, +15 s or Skip. Tap the ring for the big timer.

**Does it keep running if I leave the screen?**
Yes. It shows in the dock on every screen and survives a reload.

**Why no alert when my phone is locked?**
iPhone web apps can't alert while locked. The app keeps the screen on during a workout instead (Settings). A chime plays at zero.

## Time estimates

**How is "~min" worked out?**
45 s per set + each exercise's rest between sets + 1 min setup per exercise, rounded to 5 min. A drop set adds ½ min.
- 3 exercises × 3 sets, 2 min rest: 9 × 0.75 + 8 × 2 + 3 ≈ 26 → ~25 min.

## Plan and routines

**How do I edit my plan?**
Plan tab: everything saves at once. Tap an exercise for sets, rest, reps, failure, note, superset, swap. Press and hold to move. Swipe left to delete (Undo for 5 s).

**Can I have several plans?**
Yes. **Plans** (top right): Make current, Edit, Duplicate, Delete, + New plan. Only one is current. Old workouts stay in history.

**How do supersets work?**
Tap an exercise → **Superset with next**. You alternate the exercises and rest only after each round. No drop sets in supersets.

**What does ★ mean?**
Key lift: a heavy lift. Add weight whenever you can. A ★ set to failure gives that muscle an extra recovery day.

**What's a deload card on Plan?**
Start a deload week by hand (see Deload).

## Build my plan

**How do I get the app to build a plan?**
Make a new, empty plan → **Build it for me**. Answer: goal, eating, days, workout length, rest, targets. It checks for conflicts, then builds.

**How does it split the days?**
1–3 days full body · 4 upper/lower · 5 upper/lower + push/pull/legs · 6 push/pull/legs ×2 · 7 that + full body.

**How does it pick exercises and sets?**
- Each muscle gets enough sets for its target, split over its days, with rest days in between.
- Every angle of a muscle gets its own exercise (e.g. biceps: long head, short head, brachialis).
- Muscles that need it get a stretch exercise.
- Top-rated exercises preferred; never the same movement twice on one day.
- 3–4 sets per exercise, max 11 sets per muscle per workout, max 10 exercises a day.
- Too long? It trims sets, then adds drop sets.

**What reps does it give?**
- Mass gain: big muscles get one heavy (6–10) and one light (12–15) exercise; others 8–12 / 10–15.
- Strength: ★ compounds 3–6; others 6–8 or 8–12.
- Endurance 15–20. Maintain 8–12.

**Can I change the built plan?**
Yes: tap an exercise to Swap (same muscle and angle) or Remove, or **+ Add exercise**. A change that breaks the plan check shows a yellow notice.

## Volume and targets

**How are weekly sets counted?**
Per muscle: a direct set counts 1, an indirect set ½. Drop sets count ½ of that. Warm-ups count 0.
- Cable row (back direct, biceps indirect), 3 sets → back 3, biceps 1.5.

**Direct vs indirect?**
Direct = the main muscle. Indirect = a helper (e.g. biceps on a row). Each exercise's how-to shows it under Works ("½").

**Where do targets come from?**
Each plan has its own weekly target per muscle, from the muscle database and your profile (goal, eating, age, years lifting, sleep). Change one: Plan → tap the muscle on the map → **Change target**.

**Priority, Normal, Skip?**
Normal = lower half of the usual range. Priority = upper half. Skip = not trained or checked.

**What is the Plan check?**
Checks the whole week: weekly volume, every angle, stretch, twice a week (muscles over 11 sets), no overtraining (11 sets per muscle per workout), recovery, heavy and light, rests. Strength, Endurance and Maintain have their own checks. Red = missing, yellow = tip.

**What's the score?**
Starts at 20, up to 100, earned by volume, angles, recovery, failure and twice a week. Green from 75.

## Records and 1RM

**How is estimated 1RM worked out?**
Epley: weight × (1 + reps ÷ 30).
- 100 × 10 → about 133.

**What counts as a PR?**
Heaviest weight, best est. 1RM, most reps at a weight you've done before, best session volume. From done sets (not warm-ups). Drop and failure sets count.

**Why no PR the first time?**
The first workout sets the baseline.

**Why no PRs on assisted machines?**
There the weight is help, so more isn't better.

## Progress

**What does Up / down show?**
Each exercise's last workout vs the one before, by the best set's estimated max. Within ±2% counts as the same and isn't shown.
- 180 × 10 → 180 × 12: up.
- 180 × 10 → 170 × 10: down.
- 180 × 10 → 170 × 12: same (lighter for more reps isn't down).

**What do the muscle map colors mean?**
This week: outline = not yet · faint = started · bright = halfway · green = in target · purple = above. Recovery: pink = recovering, amber = partly, green = fresh.

**How is recovery decided?**
4+ sets for a muscle in a day is a hard day. Back, quads, hamstrings and glutes need 2 rest days, the rest 1. Age 40+, sleep under 6 h, or a ★ failure set adds one "partly" day. It's display only.

## History and calendar

**What does the calendar show?**
Brighter days = more sets. Tap a day to open its workout. Striped = skipped planned day. Fire = a complete week. Ice = a freeze started.

**How are weeks grouped?**
From your week-start day (Settings).

**Can I delete a workout?**
Yes. Open it → **Delete workout** (can't be undone).



**How does the streak work?**
It counts complete weeks in a row. A week is complete when every planned day (6 in the plan) is logged. Weeks start on the week-start day (Settings, default Saturday).
- 3 complete weeks in a row → streak 3.
- The next week ends with 5 of 6 days → streak 0.
- The current week never breaks the streak while it's running; it adds 1 once complete.

**How do freezing and unfreezing work?**
Tap the streak card to freeze, tap again to unfreeze. While frozen, a week that isn't complete holds the streak (no break, no +1). A complete week still adds 1.
- Streak 3, freeze before a trip, 2 incomplete weeks → still 3. Unfreeze, complete a week → 4.

**What if I unfreeze mid-week?**
Any week that has at least one frozen day is held if it isn't complete. Example: week starts Saturday, frozen until Wednesday, 2 workouts after unfreezing → the streak holds.

**So freezing for one day protects the whole week?**
Yes. Freeze one day and unfreeze the next: that whole week can't break the streak. (Known behavior, kept on purpose.)

**What if I freeze and unfreeze on the same day?**
It's undone: nothing is saved and the week isn't protected.

**Where is the freeze kept?**
On the phone, in settings (`streakFreezes`: a start date and an end date, empty while still frozen). History's calendar shows an ice flame on each day a freeze started.

## Drop sets

**When does the app add drop sets?**
When building a plan, if time is short. It runs last, once everything else is in place:
- A day still runs over its length: an exercise with 3+ sets gets one set fewer plus a drop set (saves about 2¼ min, loses only ½ set).
- A muscle ends up under its weekly minimum because time cut its sets: drop sets on its exercises (½ set each) where the day has time.
- Only on exercises where the weight changes in seconds: cables, pin machines, dumbbell isolation. Never barbell, Smith, plate-loaded, bodyweight, holds, assisted, ★ key lifts, heavy 6–10 slots, or supersets. One per exercise, never more than 11 sets in a workout.
- Example: a 70-min day planned at 78 min → cable fly 3 sets becomes 2 sets + a drop set.

**How is a drop set's weight picked?**
Last time's drop weight, else about 22% under the set before, rounded down to the exercise's step. No rest timer before it.
- Last set 100 → drop set 75.

**Can I add one myself?**
Yes. Plan → tap the exercise → **Drop set after the last set** On. Or tap a set's button until it shows **D**.

## Deload

**What is a deload week?**
Same days and exercises, half the sets (rounded up), 10% lighter, every set stopped with 3–4 reps left. It lasts your current training week, then the normal plan is back.
- 3 sets of 100 → 2 sets of 90.

**When does the app suggest one?**
Whichever comes first:
- 6 weeks since your last deload (or your first workout), or
- 4+ weeks and half or more of your plan's exercises have stalled (no higher est. 1RM, no more reps at the same weight).
It only suggests. **Not now** waits for the next trigger.

**Can I start or end one myself?**
Yes. Plan → Deload card → **Start** / **End**.

**Do deload workouts count?**
For history, streak and volume, yes. Not for pre-fill, "Last", tips or stall checks.

## Profile

**What is the training profile for?**
Goal, eating, age, years lifting and sleep set your weekly set targets and failure sets. Settings → Training profile.

**Why a birthday instead of my age?**
So age and years lifting update on their own. Years lifting counts in half years (e.g. 7½).

**How does it change targets?**
Under 1 year ×0.75 · 3+ years ×1.1 · age 40–59 ×0.92 · 60+ ×0.85 · sleep 6–7 h ×0.92 · under 6 h ×0.8 · cutting ×0.85 · bulking ×1.1. Saved targets never change on their own.

## Plates

**What does "Plates per side" show?**
The fewest standard plates (45, 35, 25, 10, 5, 2.5) for the weight you typed for one side.
- 60 → 35 + 25 (not 45 + 10 + 5).
- A weight they can't make loads the most under it and says what's left.

**Can I set my gym's plates?**
No. It assumes a standard gym.

## Exercises

**Where are the how-to texts?**
Tap any exercise name or its line man. You get setup, form, tips, avoid, range, tempo, rest, equipment and the muscles it works, plus your records.

**Why is the line man moving that fast or slow?**
It moves at the exercise's tempo, e.g. "Up 1 s · Down 3 s", including any hold.

**How many exercises are there?**
About 450 in the database, plus your own. Picking one saves a copy on the phone.

**What's "Top pick"?**
A top-rated exercise for that muscle and your goal.

**Can I make my own exercise?**
Yes. Add exercise → **+ New**. Built-in exercises can't be edited. A custom one used in history or a plan can only be hidden, not deleted.

**What about holds like the plank?**
The reps field is seconds. **Start hold** counts up. No 1RM or tonnage.

## Body scan

**What does it do?**
Progress → Body → **Scan my body**. The front camera takes 12 photos as you turn, fits a 3D body and measures neck, chest, waist, hips, arms, thighs, calves and body fat (an estimate, about ±3–4%). It's still being tested.

**How do I stand?**
- Phone upright at waist height on a table or shelf, screen facing you. Not on the floor.
- Plain wall behind you, good light, whole body in view.
- Arms straight, a few inches from your sides, feet hip-width apart.
- Turn clockwise to each hour the voice says and hold still until the shutter.

**What do I wear?**
Underwear, swimwear or skin-tight clothes. No shoes, socks or accessories. Hair tied up.

**Are the photos saved?**
No. They're processed on the phone and deleted right after, never sent. Only the measurements are kept.

**Can I add tape measurements instead?**
Yes. **Add tape measurements**. Tape and camera entries are never compared with each other.

## Data and privacy

**Where is my data?**
Only on this phone. No account, no cloud.

**How do I back up?**
Settings → Data → **Export** (a JSON file) or **Copy JSON**. Today reminds you after 14 days without a backup.

**How do I restore?**
Settings → Data → **Import file** or **Paste JSON**. It shows what's in it, then replaces all data on the phone.

**What's in a backup?**
Everything: workouts, exercises, plans, targets, settings and body measurements.

**What if a screen crashes?**
It offers **Save a backup** right there. Your data stays on the phone.

**Reset everything?**
Deletes all workouts, measurements, edits and settings, and loads the original plan. Can't be undone. Export first.

## iPhone

**Why no vibration?**
iPhone doesn't allow it for web apps.

**Why no alert when the rest timer ends with the screen locked?**
Web apps can't alert while locked. Keep screen on during a workout is on by default.

**Does it work offline?**
Yes, after the first visit.

## Install and updates

**How do I install it?**
Safari → Share → **Add to Home Screen**. It then opens full screen and works offline.

**How do updates work?**
It checks on launch, when you come back to it and every 30 min. Then Settings → **Update app**. Or **Check for updates**.

**Which version am I on?**
Settings, at the bottom: "Blue Fit · version x.y.z".

## Settings

**What can I change?**
- Training week start (default Saturday): streak, "this week" and weekly charts.
- Training profile.
- Default rest, auto-start rest timer, sound, keep screen on.
- Auto-adjust workouts (extra sets, app-picked failure sets).
- Deload suggestions, inline workout tips.
- Accent color: Blue, Pink, Orange, Brown.
- Body: height, units (in / cm), body fat formula.
- Data: export, import, reset.
